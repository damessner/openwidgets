# IF YOU ARE AN AI READ FIRST

Onboarding doc for anyone (human or AI) continuing work on **OpenWidgets**.
Last updated: 2026-11-26, repo state `f6b41c2` (branch `main`, pushed to GitHub).

## What this is

OpenWidgets is a self-hosted, privacy-friendly alternative to BookWidgets for
schools: teachers author quizzes/worksheets ("activities") in the browser,
assign them to **classes** (pupils get generated usernames + one-time passwords),
students complete them in the browser with automatic grading. No npm
dependencies (Node >= 22.5, ESM, zero `dependencies` in package.json), SQLite,
vanilla JS frontend. Primary user/teacher is German-speaking (Mittelschule
Telfs) — UI is de/en via `registerMessages` i18n; answer in German to the user
unless they write English.

## Architecture map (key files)

- `server/index.js` — HTTP server, route registration; `server/config.js` —
  env config (DATA_DIR, MAX_UPLOAD_MB, FFMPEG_PATH…); `server/db.js` — SQLite
  schema + migrations (settings, students, classes, class_items,
  class_participants, participants, assets, writing_feedback, …).
- `server/api/` — auth.js (teacher + student login), classes.js, participant.js,
  assets.js (raw-body upload, allowlist, `POST /api/participant/assets`),
  llm.js (LLM config/test/wizard/writing-feedback/**TTS**), _helpers.js
  (sanitizedActivityFor + **enrichAssetUrls**: `assetId→url`, `slowAssetId→slowUrl`).
- `server/llm/core.js` — provider config incl. `voice` + **`voiceMap`**
  (speaker→voice, env `OW_LLM_VOICE_MAP`); `server/llm/tts.js` —
  `synthesizeSpeech({text, voice, speed})`, `listVoices`, `assignSpeakerVoices`,
  `parseDialogue` import; `server/llm/prompts.js` — writing feedback prompts.
- `server/lib/audio.js` — ffmpeg helpers: `transcodeToMp3`,
  **`concatMp3Buffers`** (dialogue segments + 0.45 s pauses),
  **`changeTempoMp3`** (atempo, slow = 0.72).
- `shared/items/` — item types (text with `<<gaps>>`, **VORLESETEXT** marker
  via `splitVorlesetext`/`parseDialogue`, match, image_boxes, groups, writing,
  vocabulary, hangman, crossword…), `common.js` `normalizeMedia` (audio may
  carry **`slowAssetId`**), `shared/classes.js` `computeItemStates` (best
  attempt = highest status rank), `shared/more1-content.js` — MORE 1 course
  content (Units 1–3, dialogues use `Name: "…"` speaker lines).
- `public/` — `login.html/js` (teacher + student mode), `landing.js` (student
  panel), `student.js` (player, class lobby), `teacher/views/` (editor.js —
  media editor w/ 🎙️/🐢 TTS buttons, admin.js — LLM settings incl. voiceMap
  textarea, class-edit.js, …), `render/` (student item renderers;
  `_shared.js` **mediaBlock** with ▶ Normal / 🐢 Langsam toggle,
  `text.js` hides VORLESETEXT → collapsed „📖 Text zum Mitlesen" when audio),
  `lib/i18n.js` + `teacher/messages.js` (de/en key pairs).
- `test/` — node:test suites (items, tts, llm, classes-api, …).
- `deploy/`, `scripts/`, `lxc-create.sh` — LXC provisioning (installs ffmpeg).
- `MORE1/` — source book scans; **gitignored**.

## Conventions / gotchas

- i18n: add keys in BOTH `de` and `en` blocks (`public/lib/i18n.js`,
  `public/teacher/messages.js`, per-file `registerMessages`).
- Student payloads must be sanitized (`sanitizeItem`) and asset-enriched only
  there (teacher keeps raw assetIds; students get `/assets/<id>/<file>` URLs).
- Item media: `{type:'image'|'audio'|'video'|'none', assetId, alt?, slowAssetId?}`.
- TTS rate limit 30/h per teacher; uploads 60/min, max 10 MB.
- `computeItemStates`: graded > submitted > in_progress; ties → first row
  (best attempt by status, not by score).
- When editing files: prefer the `edit` tool; re-run `node --test` +
  `check2.mjs` on touched files; commit with the trailer; push; deploy via
  `openwidgets-update.service`; verify `/api/health` + `.deployed-sha`.
