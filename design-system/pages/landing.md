# Landing & Login Page Override — OpenWidgets

> Overrides/extends `design-system/MASTER.md` for `public/index.html`, `public/landing.css`, and `public/login.html`.

- **Pattern:** `Product Demo + Features` (Hero with crisp upright worksheet preview + direct student Join Code card + 3-column feature bento).
- **Motion & Framing:** Upright `.landing-mock` preview card (`transform: none`), subtle `4px` Classroom Teal top accent bar, warm amber `+1` reward chip (`--accent-soft`), no distracting floating bounce under reduced motion.
- **Student Join Card:** Highlighted `1.5px` teal-tinted border, `52px` tall uppercase monospace join-code input and CTA button.
- **Login Screen:** Clean calm teal/sand editorial backdrop (no purple blobs), full-width Teacher / Student segmented toggle, WCAG-accessible form semantics (`autocomplete` intact, paste enabled).
